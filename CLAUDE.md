# Working on this repo

- Read `PLAN.md` first: architecture, content model, design and the publishing workflow.
- When work is finished, commit, push, and **open the pull request to `main` directly**, without asking (owner's standing instruction, 2026-11-17). The owner merges; merging is what goes live.
- Build check before pushing: `bundle install && LANG=C.UTF-8 bundle exec jekyll build`; the feed must still parse, with 90+ items.
